# Ground photographs

Photographs that give the ground its grain up close in Skyview's cinematic look (docs/07 §15). Each is the colour map of a scanned surface, cut down to 512 × 512. Skyview scales each so its mean is mid-grey, and uses it to modulate the painted land cover, so the land keeps its colours.
